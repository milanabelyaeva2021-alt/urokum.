# Урокум

Освітній вебзастосунок на Node.js.

## Публікація на Render
1. Завантаж усі файли й папку `public` у корінь GitHub-репозиторію.
2. У Render створи Web Service і під'єднай репозиторій `urokum`.
3. Build command: `npm install`; Start command: `npm start`.
4. Для функцій ШІ додай `OPENAI_API_KEY` у Environment Variables на Render. Не публікуй ключ у GitHub.

PDF-файли з текстовим шаром розпізнаються автоматично. Скановані PDF потребують OCR. Дані завантажених PDF зберігаються на диску сервера; на безкоштовному хостингу вони можуть бути втрачені після перезапуску або redeploy. Це початкова версія без облікових записів і синхронізації прогресу.
