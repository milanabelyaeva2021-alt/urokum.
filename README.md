# Урокум — інтерактивний підручник

Вебзастосунок для читання PDF-підручників, навігації за змістом та навчання з AI-перевірками.

## Запуск локально

1. Потрібен Node.js 20 або новіший.
2. Виконай `npm install`.
3. За потреби створи `.env` на основі `.env.example` та додай `OPENAI_API_KEY`.
4. Запусти `npm start`.
5. Відкрий `http://localhost:3000`.

## Розгортання на Render

Проєкт містить `render.yaml`. Build command: `npm install`. Start command: `npm start`. Додай `OPENAI_API_KEY` у Environment, щоб увімкнути пояснення та AI-тести.

Для збереження завантажених PDF між перезапусками Render потрібен Persistent Disk, змонтований у директорію `uploads` (або інше постійне сховище). Без нього завантажені користувачами файли можуть зникнути після перезапуску сервісу.

## Як працює зміст

- Спочатку читається вбудований PDF Outline (закладки/структура документа) разом із цільовими сторінками.
- Якщо Outline відсутній, застосунок шукає в текстовому шарі назви на кшталт `РОЗДІЛ`, `ТЕМА`, `§ 1`, `ПАРАГРАФ 1` і визначає орієнтовні діапазони сторінок.
- Автоматичне визначення залежить від якості PDF та форматування. Будь-який пункт можна вручну додати, змінити або видалити; зміни зберігаються на сервері.
- PDF показується в оригінальному вигляді, тому зображення, карти й таблиці не втрачаються.

## Обмеження

- Скановані PDF без текстового шару потребують OCR. Оригінал усе одно можна переглядати, але AI-пояснення та автоматичний зміст потребують розпізнаного тексту.
- Каталог авторів поки демонстраційний лише для одного конкретного видання; для інших предметів застосунок не вигадує список підручників — можна завантажити власний PDF.
- AI-функції працюють лише після налаштування `OPENAI_API_KEY`.
