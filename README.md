# Урокум — інтерактивне читання та перевірка знань

Україномовна навчальна платформа для читання електронних підручників і перевірки розуміння матеріалу.

## Що вже працює

- Електронний підручник «Історія України», 11 клас, О. Гісем / О. Мартинюк (2019, рівень стандарту).
- § 1–2: структуровані вручну HTML-тексти, таблиці, словнички, історичні джерела та готові самостійні роботи (по 12 запитань).
- Інші параграфи: текст тимчасово виділяється сервером із PDF; його правильність і структуру **ще потрібно вручну перевірити**.
- Після кожного пункту: 4 тести з варіантами й 1 письмове запитання; учень може пропустити завдання.
- Після параграфа: самостійна робота (9 тестових і 3 письмові); для § 1–2 запитання вже підготовлено, для інших генеруються з кешуванням.
- Показ джерела для помилок, переказ, короткий конспект, збереження прогресу в браузері.
- Ручне перенесення прогресу між пристроями через файл: у читалці відкрий **Зміст → Перенести прогрес між пристроями**.
- Фіолетовий інтерфейс, мобільне оформлення, змінюваний розмір шрифту.

## Запуск

Потрібен Node.js 20+.

```bash
npm install
npm start
```

Відкрий `http://localhost:3000`. На GitHub і в коді сайту **не повинно бути таємних API-ключів**. Для Render ключі додаються виключно через Dashboard → Environment.

## Налаштування ШІ

Платформа може працювати з безкоштовними квотами цих провайдерів, у порядку:

1. `GEMINI_API_KEY` — модель `GEMINI_MODEL`, типово `gemini-2.5-flash-lite`.
2. `GROQ_API_KEY` — модель `GROQ_MODEL`, типово `openai/gpt-oss-20b`.
3. `OPENROUTER_API_KEY` — модель `OPENROUTER_MODEL`, типово `openrouter/free`.

Платний OpenAI використовується лише якщо **`ALLOW_PAID_AI=true`** та встановлено `OPENAI_API_KEY`. Сам по собі `OPENAI_API_KEY` не вмикає платні звернення.

Для API `/api/tutor` діє обмеження **20 запитів за 10 хвилин з однієї IP-адреси** (налаштування для малого односерверного проєкту). Обмеження захищає безкоштовні квоти, але учні за однією шкільною мережею можуть спільно досягти ліміту. Кешовані тести не потребують нових генерацій. Лічильник зберігається в пам’яті та обнуляється при перезапуску; для кількох інстансів потрібне спільне сховище на кшталт Redis.

Тексти учнів — **недовірені дані**. Оцінювання письмових відповідей використовує чіткі інструкції та JSON-поля, але автоматичне оцінювання ШІ може помилятися. Не використовуй його як єдине джерело підсумкової шкільної оцінки.

## Адміністрування PDF

Публічні маршрути читання збереглися. Маршрути, які **змінюють дані**, закриті:

- `POST /api/upload`
- `PUT /api/book/:id/outline`

Без секрету вони повертають HTTP 403. Якщо потрібен редактор PDF, додай у Render Environment змінну `UROKUM_ADMIN_TOKEN` із випадковим секретом **не коротше 24 символів**. Авторизований запит повинен передавати секрет лише через HTTPS у заголовку `X-Urokum-Admin-Key`. **Ніколи не клади реальний секрет у GitHub, README чи браузерний код.** Для цих дій додатково діє обмеження 3 запити/годину з однієї IP.

Вкладка читання оригінального підручника та готові питання не потребують адміністративного ключа.

## Збереження прогресу

Прогрес поки що зберігається в `localStorage` конкретного браузера. Учень може експортувати файл `urokum-progres.json` та імпортувати його на іншому пристрої. **Автоматичної синхронізації, реєстрації, справжнього особистого кабінету й бази даних ще немає**. Не передавай експортований файл стороннім — він містить результати навчання.

## Render

`render.yaml` налаштований на запуск Node-сервісу, `/api/health` використовується для перевірки доступності. На безкоштовному Render після простою може бути холодний старт. Налаштування health check **не усуває** обмеження безкоштовного тарифу.

Вбудовані `/api/health`, `/api/ai-status` можуть перевірити стан сервера та факт конфігурації ШІ без розкриття ключів.

## Джерела та авторські права

Видання: **О. В. Гісем, О. О. Мартинюк. «Історія України» для 11 класу, рівень стандарту (2019)**. Оригінальний електронний підручник доступний у [бібліотеці ІМЗО](https://lib.imzo.gov.ua/). Для PDF на сервері використовуються джерела видавництва «Ранок» або ІМЗО; сторонні файлові дзеркала прибрано.

**Увага:** наявність підручника у вільному доступі для читання **не означає автоматичного дозволу** на повторну публікацію його повного тексту як HTML/JSON на сторонній платформі. Перед масштабуванням перевір умови ліцензії, право на адаптацію й повторне поширення та за необхідності отримай дозвіл правовласника. Юридичну перевірку ще не завершено. Це не твердження про наявність дозволу.

## Технічні файли

- `server.js` — Express API, екстракція PDF, безпека і ШІ.
- `public/index.html` — головна сторінка та каталог.
- `public/electronic-reader.html`, `public/electronic-reader.js` — сучасна електронна читалка.
- `public/books/h11/` — зміст, структуровані §1–2 та готові самостійні роботи.
- Старі `page-reader.html`, `e-reader.html` і пов'язані скрипти можуть залишатися у репозиторії як попередні версії: перед видаленням потрібно перевірити всі посилання на них, щоб не порушити існуючі переходи.
